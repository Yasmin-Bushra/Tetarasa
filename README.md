# Tetarasa (ትታረሳ)

### Connecting Mothers with Postnatal Care

Tetarasa is a web platform designed to help mothers discover postnatal care services and connect with caregivers. The project aims to make accessing support after childbirth easier through a simple, user-friendly digital experience.

## About the Project

The postnatal period is an important stage in a mother's recovery and well-being. Tetarasa aims to bring mothers and caregivers together through a platform where mothers can explore care options and caregivers can offer their services.


## Key Features

- **Mother Authentication:** Registration and sign-in interfaces for mothers.
- **Role Selection:** Separate entry points for mothers and caregivers.
- **Mother Dashboard:** A dedicated interface for mothers to access their account and care-related features.
- **Caregiver Discovery:** Planned functionality for exploring caregiver profiles.
- **Care Requests:** Planned functionality for requesting and managing postnatal care.
- **Role-Based Dashboards:** Planned separate experiences for mothers, caregivers, and administrators.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Yasmin-Bushra/Tetarasa.git
```

**2. Open the project directory**

```bash
cd Tetarasa
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

*These instructions cover the frontend when the root project is configured with the standard Vite scripts.*
